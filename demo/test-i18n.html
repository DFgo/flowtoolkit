防抖功能说明

频繁调用 refresh() 或 changeLang() 时，会防抖处理，避免重复执行 DOM 操作。
默认延迟 200ms，可通过 debounceDelay 配置。

// 方式1：从 URL 加载 await i18n.loadMessagesAsync('ja', 'https://example.com/i18n/ja.json'); i18n.changeLang('ja'); // 方式2：通过函数加载 await i18n.loadMessagesAsync('fr', async (lang) => { const response = await fetch(`/api/i18n/${lang}.json`); return await response.json(); }); // 方式3：批量加载 const languages = ['en', 'ja', 'ko']; await Promise.all( languages.map(lang => i18n.loadMessagesAsync(lang, `/i18n/${lang}.json`) ) );
